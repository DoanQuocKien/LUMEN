# Relevance judging guidelines (draft, finalize in W1-B1)

Judge each (query, post) pair by reading the post title, body **and** attachment text.

| Grade | Meaning | Example (query: "danh sách đăng ký HB KKHT HK1 2026-2027") |
|---|---|---|
| 2 | Directly answers the query: the post a student needs | "Thông báo số 2 về danh sách đăng ký HB KKHT HK1 2026-2027" |
| 1 | Related and partly useful: same topic, older or adjacent notice, or a regulation behind it | Notice số 1 of the same series; the HB KKHT regulation |
| 0 | Not useful | A scholarship from a different sponsor; an unrelated decision |

Rules:
- Judge without seeing which system retrieved the post or at what rank.
- For time-bound queries, an outdated semester counts as 1 at most.
- If you can't decide between two grades, choose the lower one and add a note.
- Mark a query `no_answer` if nothing in the pool deserves 2.
- Never copy student names or MSSV into notes.
